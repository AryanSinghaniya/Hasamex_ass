# Hasamex AI Engineer – Technical Case

## Objective
Build a simple app that analyses 3 expert-call transcripts from the same project.

## Your app should:
1. Upload/read the 3 transcripts.
2. Answer the interview-guide questions for each expert.
3. Extract useful exact quotes.
4. Show the source timestamp for each answer/quote.
5. Identify common themes and disagreements across all 3 experts.
6. Let the user ask questions across all transcripts.

## Important
- Do not invent information.
- Every important answer should be traceable to the transcript.
- Keep the UI simple and usable.

## Demo
In the technical round, please show the app and explain:
- your architecture,
- model choice,
- how you handle citations/timestamps,
- how you reduce hallucinations,
- how you would scale from 3 transcripts to 30+.

## Submit
- Working app or local run instructions
- Source code repository
- Short README
